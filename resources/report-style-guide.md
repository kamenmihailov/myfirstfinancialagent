# Report Style Guide

Rules that apply to every research report, regardless of topic or section structure.

---

## Format

- **Bullet points over prose** — every section leads with bullets, not sentences
- **Bold key numbers, percentages, and named entities** — e.g., **73%**, **$2.4B**, **EU AI Act**
- **Section length** — 3–6 bullets per section; split into subsections if more is needed
- **No jargon without a gloss** — if a term requires domain knowledge, follow it with a brief parenthetical explanation on first use

## Voice

- **Direct** — state findings as facts, not possibilities ("adoption doubled" not "adoption may have doubled")
- **No hedging language** — avoid "it seems", "might be", "could potentially"
- **No filler** — no intro sentences that restate the section title; get to the data immediately

## Structure (every report)

Every report must end with these three sections, in this order, before anything else closes the file:

1. `## Key Takeaways` — 3–5 bullets; the single most important thing to understand from the research
2. `## Recommended Next Steps` — 3–5 actionable bullets written for the stated audience
3. `## Sources` — minimum 4 sources, each as a titled markdown link (never a raw URL)

## Metadata

- Date-stamp every report on line 2: `*Research date: YYYY-MM-DD*`
- Use the actual research date, not a publication or event date

## Sources

- Minimum 4 sources per report
- Format: `- [Descriptive title | Publisher](URL)`
- Prefer primary sources: original studies, official statistics, named experts
- If two sources contradict each other on a key fact, cite both and note the discrepancy inline
